# assets/

Empty on purpose. No logo, photography or icon files came with the brief, and this
system does not draw a company's mark from imagination.

Intended contents when real material arrives:

- `logo.svg` — horizontal lockup, plus `logo-stacked.svg` and a mono/knockout version
- `photos/` — crew at work, before/after yards, equipment; warm mid-morning daylight, unfiltered
- any custom marks that should replace Lucide glyphs

Until then, the brand name set in Archivo Expanded 800 stands in for the mark
(see `guidelines/brand-wordmark.html`), and `PhotoSlot` in `ui_kits/website/Sections.jsx`
stands in for photography.
