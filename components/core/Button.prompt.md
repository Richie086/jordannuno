Primary action control — use for anything the visitor or crew clicks to commit (Get a quote, Save job, Dispatch).

```jsx
<Button variant="accent" size="lg" iconRight={<Icon name="arrow-right" />}>Get a free quote</Button>
```

Variants: `primary` (green, most actions) · `accent` (clay, one per screen, booking/urgency) · `secondary` (outlined, paired second action) · `ghost` (toolbars, tertiary) · `inverse` (on dark green sections). Sizes sm/md/lg — md is 44px tall, the minimum touch target. `href` swaps the element to an anchor.
