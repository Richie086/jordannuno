Lucide glyph wrapper — the system's only icon source. Host page must load `https://unpkg.com/lucide@0.451.0/dist/umd/lucide.js`.

```jsx
<Icon name="leaf" size={20} />
```

Default stroke width is 1.75. Brand-favoured glyphs: leaf, sprout, trees, shovel, truck, calendar-days, map-pin, droplets, sun, phone, clipboard-list, scissors.
